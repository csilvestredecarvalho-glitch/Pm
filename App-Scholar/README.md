AppScholar 

Projeto Acadêmico — Aplicativo Mobile desenvolvido em React Native / Expo.

 Sobre o Projeto

O AppScholar é uma aplicação mobile desenvolvida com o objetivo de oferecer uma solução prática, moderna e intuitiva no contexto educacional e de gestão acadêmica.

O projeto foi construído utilizando a plataforma Expo e a biblioteca React Native, visando a entrega de uma experiência multiplataforma (Android, iOS e Web) com interface responsiva e alinhada às boas práticas de desenvolvimento mobile.

Tecnologias Utilizadas

O desenvolvimento do projeto contou com o seguinte ecossistema tecnológico:

React Native: Framework para desenvolvimento de aplicações mobile nativas.

Expo: Plataforma e conjunto de ferramentas para acelerar o fluxo de desenvolvimento React Native.

JavaScript / TypeScript: Linguagem base para construção da lógica e componentes.

JSON: Utilizado na configuração do projeto (app.json).

 Funcionalidades Principais

O aplicativo possui as seguintes funcionalidades centrais:

Autenticação e Perfil do Usuário

Suporte à navegação fluida para acesso de alunos, professores ou administradores.

Interface configurada para adaptação de tema (suporte ao modo claro/escuro).

Gestão Acadêmica e Conteúdos

Visualização de informações escolares/acadêmicas centralizadas.

Design moderno voltado para facilidade de leitura e usabilidade em telas portrait (retrato).

Suporte Multiplataforma

Android: Compatibilidade completa com ícones adaptativos e suporte a layout edge-to-edge.

iOS: Suporte estendido para smartphones e tablets.

Web: Execução e visualização direta pelo navegador via Expo Web.

 Como Executar o Projeto

Pré-requisitos

Node.js (versão LTS recomendada)

Gerenciador de pacotes (npm ou yarn)

Aplicativo Expo Go instalado no dispositivo móvel (para testes físicos) ou um Emulador Android/iOS.

Passo a Passo

Clonar o repositório:

git clone https://github.com/seu-usuario/appscholar.git
cd appscholar


Instalar as dependências:

npm install
# ou
yarn install


Iniciar o servidor de desenvolvimento Expo:

npx expo start


Executar a aplicação:

Escaneie o QR Code exibido no terminal utilizando o app Expo Go no smartphone.

Ou pressione a para abrir no emulador Android, i para iOS, ou w para abrir no navegador.
